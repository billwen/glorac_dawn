# Findings

- All existing English storefront keys have Swedish counterparts, including plural forms.
- Shared editorial footer, browser titles, homepage CTA prefixes, product description fallback, and mobile collection accessibility label bypass translations.
- Homepage, announcement, password launch text, collection-list heading, related-product heading and Share label have known English settings to translate.

- About captions translate only known default English values; custom values depend on Shopify translation.
- Header language selector is enabled. No Shopify connector, CLI configuration, or live content export is present.
